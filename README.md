# Agile MLOps Demo — Iris Classification

This project demonstrates a small machine-learning workflow alongside Agile Scrum documentation.

## Project contents

- `src/iris_demo.py` — trains, evaluates, saves, and reloads a Decision Tree classifier.
- `tests/` — automated tests for predictions, accuracy, and model saving.
- `.github/workflows/ci.yml` — GitHub Actions workflow that runs tests on every push and pull request.
- `models/` — saved model artifact generated by the script.
- `docs/` — Product Backlog, Sprint Planning, Daily Scrum, Sprint Review, and Sprint Retrospective.

## Run locally (Windows)

Open a terminal in the project root, then run:

```powershell
python -m venv .venv
.\.venv\Scripts\activate
python -m pip install -r requirements.txt
python src/iris_demo.py
```

## Run automated tests

```powershell
python -m pytest -v
```

## CI/CD demonstration

The GitHub Actions workflow in `.github/workflows/ci.yml` installs dependencies, runs automated tests, executes the Iris demo, and uploads the trained model as a downloadable workflow artifact whenever code is pushed or a pull request is opened. To demonstrate it, push the project to GitHub and open the repository's **Actions** tab. After a successful run, open the run and download the `iris-trained-model` artifact.

## Agile/Scrum documentation

See `docs/` for the Product Backlog, Sprint Planning, Daily Scrum, Sprint Review, and Sprint Retrospective records.
